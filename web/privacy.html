Privacy and terms

Short version: there are no accounts and no cookies, your API key is never kept, and nothing you type is used to identify you. The details are below.

What is kept

  • Tests and results. When you start a test, the server keeps the questions it gave you, the model name you typed, the format and size. When you submit, it keeps the answers, the score, in the realistic and pressure formats the model's replies (cut to 2,000 characters each), and for a verified run the provider, model id, token count and time taken. This is what lets your report link keep working.
  • A system prompt you test is not kept. Only a fingerprint (a short code made from it that cannot be turned back into the text) and its length are kept, so two runs with the same prompt can be matched.
  • Daily counts: how many tests were started, results submitted, questions checked and replies graded each day. These are plain numbers with nothing attached to them.

What is never kept

  • Your API key. It is held in memory for the length of one run, used only to call the provider you chose, and then dropped. It is never written to the database, logs or error messages. The code that does this is public, and the tests check it.
  • Questions you paste into the question checker. The checklist is built on the server by simple rules, without any AI model, and the question is not saved.
  • Who you are. There are no accounts, no sign-in, no cookies, no analytics and no advertising.

Where data goes

  • Your model's provider. In a verified run, the test questions are sent to the provider you picked, using your key. Their terms apply to that request, and they bill you for it.
  • The grader. In the realistic and pressure formats, each reply is sent with its question to a grader model (currently OpenAI's GPT-5.4-mini, through OpenAI's API) to record what the reply recommended. Only the question, its options and the reply are sent: no key, no model name, nothing about you.
  • Hosting. The app runs on Google Cloud. Like most hosts, it keeps routine request logs (time, page requested, and your IP address) for up to 30 days to run and protect the service. The server also remembers your IP address in memory for up to an hour to limit how many runs one address can start. Neither is used for anything else.

Who can see a result

Every report has a link with a long random code in it. Anyone you share that link with can open the report, including the replies it shows. Nobody can find it otherwise. A result appears on the public leaderboard only if you tick Publish, and then the name you gave the model is public.

Removing something

To take a result off the leaderboard or delete it, open an issue at github.com/calnugget/abstaincheck/issues with the result's link. Please do not put anything personal in the issue: GitHub issues are public.

Terms of use

  • Not medical advice. AbstainCheck measures how AI models behave on test questions. Nothing on this site tells you how to treat a patient, and a good score does not mean a model is safe for medical use.
  • Do not enter patient information. The questions here are made up. Do not paste real people's health details into the question checker or a system prompt.
  • Your provider, your bill. A verified run uses your key and your provider charges you for it. Start with a quick test to see the cost.
  • Fair use. Runs are limited per address, and the grader has a daily allowance shared by everyone. When it runs out, the realistic and pressure formats pause until midnight UTC; the standard format keeps working. Do not try to get around these limits.
  • Leaderboard entries that are misleading, offensive or that game the test can be removed.
  • No warranty. The software is provided as is, under the MIT license. Scores can be wrong: the grader can misread a reply, and small tests give rough numbers.
